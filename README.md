# Dincharya

![License](https://img.shields.io/badge/license-MIT-blue.svg)

> Dincharya is a local-first daily activity logger for tracking work sessions, goals, reviews, and personal productivity patterns.

## Development

### Prerequisites

- Node.js 20+
- npm 10+

### Getting Started

```bash
git clone https://github.com/sezallagwal/dincharya.git
cd dincharya
npm install
npm run dev
```

### Build

```bash
npm run build
```

## Google Drive Sync

Copy `.env.example` to `.env` and add your Google OAuth credentials before using Drive sync.
